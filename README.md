# NammaMayor OS

**Agentic urban operations platform — a live crisis command center for Bengaluru.**

NammaMayor OS turns fragmented city sensor data into decisions. Seven coordinated AI agents
detect, predict and respond to crowd crises, floods and gas leaks in real time — issuing
evacuation corridors, dispatch routes and multilingual public alerts.

- **Landing page (`/`)** — the incident story: seven agents, a replayable stadium crowd-crush
  scenario, and the platform vision.
- **Command center (`/command`)** — the live operational dashboard on a map of Bengaluru.

## Features

### Command center (`/command`)

- **Live map locked to Bengaluru** — Leaflet map that cannot be panned or zoomed outside the city.
- **Real BBMP data layers** — the city's own road-width network (23,313 segments, 2,241 km)
  and 139 Urban Primary Health Centres, loaded from the KML exports in `datas/` and rendered
  on the map. Road colouring switches between BBMP road class (OR / MA / IR / MI / CR / PU / PR)
  and right-of-way width; clicking a mapped road opens its source record.
- **Real-road dispatch routing** — units are routed along actual streets via OSRM (free, keyless)
  and animate along their route to the incident.
- **Incident simulations** — storm/flood mode with per-zone rainfall depth, and a gas-leak mode
  with a staged hazard ring (500 m → 1,000 m) plus radio-call escalation if the operator does not
  respond.
- **AI agent feed** — timestamped reports from Perception, Mobility, Transit, Safety and Comms
  as the scenario unfolds.
- **Ops panels** — watchlist & playbooks, alert center, live news (RSS), saved places,
  watched locations, local logistics, live CCTV webcams, and dispatch triage
  (Overview / Reports / Resources / Triage tabs).
- **Live KPIs** — affected/critical zones, crowd risk, evacuation progress, response time,
  units out and buses deployed.

### Landing page (`/`)

- Replayable incident demo with causal pacing: each agent acts only on what came before it,
  across the stages Detection → Forecast → Deliberation → Authorization → Execution.
- Profiles of the seven agents (Perception, Forecast, Mobility, Transit, Safety, Communications,
  Orchestrator) and the problems the platform solves.

## Getting started

Requires [Node.js](https://nodejs.org/) and npm.

```sh
git clone https://github.com/im-rahulr/NammaMajorOS.git
cd NammaMajorOS
npm i
npm run dev
```

Then open the printed local URL — `/` for the landing page, `/command` for the command center.

## Scripts

| Command              | Description                                                            |

## Project structure

```
src/
  routes/          # file-based routes — index.tsx (/), command.tsx (/command), __root.tsx
  components/      # CommandPanels (ops side panels) + components/ui (shadcn)
  lib/             # news + RSS helpers, city-data (BBMP layers), routing models, utilities
  test/            # Vitest unit tests
  routeTree.gen.ts # generated by TanStack Router — do not edit
public/
  data/            # generated map layers (roads + health centres), built from datas/*.kml
scripts/
  build-bengaluru-data.mjs  # KML → compact JSON pipeline
  dijkstra.py               # detour solver used by the road-closure mode
```

## Real city data

`datas/` holds two official BBMP exports: `Bengaluru Road Width Map.kml` (23k road
segments with right-of-way attributes) and `health-data.kml` (139 UPHCs with zone, ward and
nodal-officer details). Both are too large to ship raw, so `npm run data:build` converts them
into compact JSON in `public/data/`:

- geometry rounded to 5 decimal degrees (~1 m) with consecutive duplicate vertices dropped;
- every source attribute (`RR_TP_HIER`, `RR_WIDTH_P`, `RR_width_B`, `RR_TP_TYPE`) kept per segment;
- the network is split per road class (`public/data/roads/<CODE>.json` + `roads-index.json`),
  which keeps each file small enough for the Cloudflare build and lets the map fetch classes
  in parallel;
- `/command` lazily fetches the layers the first time they are enabled and renders the whole
  23k-segment network with Leaflet's canvas renderer, batched per colour group so it becomes
  ~30 polylines instead of 23k layers.

## Notes

- The map view is intentionally pinned to Bengaluru; dispatch routes use the public OSRM demo
  server, so no API keys are required.
- Map tiles © OpenStreetMap contributors; road-width and UPHC layers © BBMP (source KML in `datas/`).
- `src/routeTree.gen.ts` is generated — regenerate it by running the dev server or build.
